# トイモデル v2 の結果の論文への寄与（2026-10-26）

## 0. 前提

- トイが準拠した本文は、トイ作成時点の本文である（公開する原稿との関係は総括 0 節）。三原理は SM・EU・FR で、$\mu_{\mathrm{eff}}$ は診断量として扱われている。
- 数値はすべて 8 シナリオ（各 300 ステップ、`long` のみ 600 ステップ）の記録からの実測である。
- トイの数値は、現象が現れるように私が調整した。したがって、現象の**頻度**や**崩壊時刻**には情報価値がない。寄与として数えられるのは、「ある実現が存在する」「ある含意が成り立たない例がある」という**存在の水準**のものに限る。

## 1. 寄与（主張の強さとあわせて）

### 1.1 定義系が同時に充足可能であることの一例

- 有限・決定論的な一つの実現で、次の条件と定義が同時に満たされた（`checks.txt`、全シナリオ NG 0）。
  - CR-1（(a)(i)・(a)(ii)・(b)・(c)）
  - CR-2（(a)〜(c)）
  - §2 の仮定 f_decomposition・env_input_nondegeneracy・env_viable_nondegeneracy・viable_realizability・compact_spaces・M_compact
  - §2〜§8 の各定義
- 主張できる強さ：これらの条件の組が空でない（矛盾しない）ことを示す**一つのモデルの存在**。
  - CR-1a(ii)・(SC-2)・(FT-2) は格子での検査とコードの目視によるもので、厳密な証明ではない。
  - §3〜§6 の仮定（theta_exterior_blockage など）は検査していない。

### 1.2 本文が区別する概念が、実際に分かれる例

いずれも「一般には成り立たない含意」の具体例である。反例としては一例で足りる。

| 本文の区別 | トイでの実例（実測） |
|---|---|
| 閉塞 ≠ 崩壊（$A_t=\emptyset\not\Rightarrow\mathrm{Col}_t=1$） | default の i：t=153 で閉塞し、t=154 に自律的に回復 |
| (B1) と (B2) の両方が実際に生じる | default：i は B1 3・B2 7、j は B1 2・B2 13。rocky では B1 は 0 |
| 機能的終端は崩壊に先行しうる（$T_{\mathrm{FT}}<T_{\mathrm{col}}$） | default の j：FT 178、Col 180。ほか 8 例 |
| $x\in\mathrm{Viab}_f(K)$ でも、実現軌道は後に崩壊しうる | default の i：最後に in と判定されたのが t=240、崩壊は t=260 |
| 実現した救助は $e_t$ を通じてだけ効き、$\upsilon$ は判定にだけ使う | 相手・ドローン・組織の贈与による閉塞の解消を、$e_t$ の贈与成分の反実仮想で識別した |
| 外的回復可能性は崩壊の前に狭まりうる | default の i：Recover は t=165 で `110`、t=253 で `100` |
| 個体の崩壊 ≠ 組織水準の崩壊 | default：j の崩壊（t=180）で組織 ACS は不成立になったが、組織の CS は i の崩壊後（t=261）に初めて成立した |

最後から二番目の Viab の例は、本文の非主張を具体化している。核は $E_{\mathrm{req}}$ 上の頑健性であり、実現した $e_t$ が $E_{\mathrm{req}}(x_t)$ の外に出ること（default の i で 58 時刻）や、機構が核にとどまる応答を選ばないことを排除しない。

### 1.3 $\mu_{\mathrm{eff}}$ を原理から外した判断を支える例

- 全 15 個体記録で、状態帯 Z0（通常作動）の時刻のすべてで $\mu_{\mathrm{eff}}=1$ だった（例：default の i で 220/220）。$\mu_{\mathrm{eff}}\ge2$ になった生存時刻は、個体あたり 0〜7 時刻しかない。
- 理由は定義から読み取れる。どの行動も $E_{\mathrm{req}}(x)$ 全体で可行性を保つ安全な状態では、すべての $\varphi_u$ が恒等的に 1 になり、同値類は一つになる。
- このため、仮に $\mu_{\mathrm{eff},t}\ge2$ を原理の充足条件とする定式化を置くと（本文はそうしていない）、このモデルでは通常作動の全時刻がその条件の不成立と判定される。
- これは「$\mu_{\mathrm{eff}}\ge2$ は通常作動の必要条件ではない」ことを示す一例である。本文が $\mu_{\mathrm{eff}}$ を「いずれの原理の時刻別充足述語の定義にも用いない」診断量としていることと整合する。
- ただし、この観察は一つのモデルについてのものである。$\mu_{\mathrm{eff}}$ の診断量としての有用性を評価したものではない。

### 1.4 機構と判定の分離が実装できること

- 機構（TIPA・PSL・ISL）は真の $\Pi$・$A_t$・$\mathrm{Crit}^{(1)}$・$\mathrm{Viab}$ を一切参照せず、判定層だけがそれらを計算する構成で、全体が作動した（§1 の形式表現と ACS 内部認識の区別）。
- 次のインターフェース条件は、同時に満たせることを記録上で確かめた。
  - $g_O$ が個体の $M$ に依存しない。
  - 観測による因数分解（$u_t$ が $(M_t, P_{\mathrm{sens}}(x_t,e_t))$ だけで決まる）。
  - M2 が M3 を参照しない。
  - 記録の再計算が一致する。
- 主張できる強さ：§4・§5 の標準形式が少なくとも一つの実装で整合して組み上がる、という存在の水準。

### 1.5 「対象系ごとに固定する判定規則」の具体的な負担の特定

本文が対象系ごとの判定規則や Phase 1.α に委ねている部分を、実際に固定する必要があった。

- WF、(SC-1)・(SC-2)、(FT-1)・(FT-2)、活動
- 状態帯 Z1〜Z4、Recover の判定規則と地平
- $\chi_{\mathrm{EI}}$ の境界横断作用
- §6 のカテゴリーの記録規則と $Q$ の規則
- $d_{\mathrm{eff}}$、偏向の基準

これらは README §7 に一覧にしてある。Phase 1.α や §9 の限界で「判定規則が非一意で、結果がそれに依存する」と述べる際の具体例として使える。

### 1.6 計算可能性の限界の具体化

- $\mathrm{Viab}_f(K)$ の所属判定は、有限で小規模なこのトイでも全探索が現実的でなかった。そのため証明書方式（不変集合を構成できれば in、$\mathrm{Hor}_f$ が有限なら not_in）に切り替えた。
  - rocky では「未決定」が 5 回残った。他のシナリオでは 0 回。
- $\mathrm{Viab}^{\mathrm{resp}}_f(K)$（機構の内部状態を含む積空間上の核）は計算できなかった。
- これは、§9 の推定誤差・崩壊の観測可能性に関する未解決問題に、具体的な計算上の裏づけを与える。

### 1.7 構築中に見つかった、構成要件の実質性

- 当初、「閉じた避難所で休むとエネルギーを消費しない」状態を置いた。この状態があると、食料の非充足が続いても存続できてしまい、CR-1a(ii) が満たされなかった。
- これは、CR-1a(ii) が「無費用で持続できる状態」をもつ設計をモデルの類から除く、実質的な制約であることを示す例である。
- これはトイの設計上の発見であり、本文の欠陥ではない。

## 2. 寄与しないもの

- 本文の命題の証明の補強にはならない。記録上の再検査（RECORD）は実装の誤りを検出するためのもので、命題を経験的に確かめたことにはならない。
- 一般的な傾向（協力は存続を延ばす、孤立は不利、など）は何も示さない。
  - 例：alone は 300 ステップを生き延び、他は崩壊した。
  - 数値の調整で結果は大きく動いた。
  - 現象が出るように調整したという選択の偏りがある。
- Phase 2 以降（確率・連続時間・分岐する同一性）に関わる内容は含まない。
- 現実の系（生物・AI・組織）への適用可能性については何も示さない。
