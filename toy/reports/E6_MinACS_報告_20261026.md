# E6 MinACS：全数計算による最小実現の報告（2026-10-26）

準拠本文：トイ作成時点の本文（公開する原稿との関係は総括 0 節）。
実行：`python3 run_e6.py out_e6`、続いて `python3 report_e6.py out_e6`。標準ライブラリのみで、全計算は 0.4 秒（実測）。

## 1. 何をしたか

v2 では、全称量化を含む主張を格子上の検査とコードの目視で扱っていた。E6 では、すべての集合が全数で計算できる大きさの実現を作り、次を有限の全数計算で確かめた。

- 構成要件（CR-1・CR-2）と §2 の仮定
- §3・§7 の各集合
- 命題の成立

この実現の上では、検査の結果はそのまま証明になる（有限集合上の全数検査）。

## 2. MinACS の仕様（トイ規約）

| 成分 | 内容 | 大きさ |
|---|---|---|
| $X$ | $x=(p,en,tp,s)$。$p\in\{0{:}\text{避難所},1{:}\text{資源}\}$、$en\in\{0..5\}$、$tp\in\{0,1,2\}$、$s\in\{0,1\}$（構造） | 72 |
| $U$ | {wait（$u_\emptyset$）, L, R, eat} | 4 |
| $E_{\mathrm{ext}}=E^{\mathrm{bg}}\times O$ | $b=(c,g,\rho)$：寒さ、贈与（+2）、資源の再生。$o=r$：資源の有無 | 16 |
| $E$ | $\eta_{\mathrm{heat}}=1 \iff c=0$ または $p=0$。$\eta_{\mathrm{food}}=1\iff r=1$ または $g=1$ | 2 |
| $\Pi$ | $\min(en-1,\,tp-1,\,s-1)$ | |
| $f$ | $\oplus(f_{\mathrm{auto}},f_{\mathrm{dir}})$、$\oplus(a,b)=\mathrm{clip}(a+b-o^\ast)$ | |
| $g_O$ | $\rho=1$ なら $r'=1$。そうでなければ、食べられれば $r'=0$、それ以外は $r'=r$ | |
| $M$ | M1：信念（寒さ、資源）、M2：単点（学習しない因子）、M3：目的の記録 | 12 |

$f$ の中身は次のとおり。

- $f_{\mathrm{auto}}$：代謝 −1、贈与 +2。
- 体温：避難所の中か寒くないときは +1、それ以外は −1。
- 構造の喪失：$en=0$ で贈与がない、または $tp=0$ で寒さにさらされると、構造が失われる（$s=0$）。$s=0$ は凍結する。
- $f_{\mathrm{dir}}$：L・R で移動、資源セルで $r=1$ なら eat で +3。
- 判定規則：WF $=s$、(SC-1) は $s=0$、基盤機能の活動は $s=1$ かつ $en>0$。
- 許容外的作用 $\Upsilon_{\mathrm{adm}}$ = {inject：+2、warm：$tp=2$、carry：避難所へ}。

機構（TIPA の最小形）は、避難所の中では天候が見えず、資源は資源セルでしか見えない。見えないものは記憶（信念）で補う。

## 5. 読み取れること

### 5.1 定義域の制限のもとで許される 6 通りの判定の組がすべて現れる（$\mathbb{T}_{\mathrm{P}}$ 上の全組）

FR は EU が偽の時刻には定義されないので、三つの述語は独立な二値述語ではない（当初の版の見出し「互いに独立に真偽をとる」は不正確だった）。下の表で FR が「未定義」の組は、FR 偽として数えていない。

| (SM, EU, FR) | 組数 |
|---|---|
| (真, 真, 真) | 258 |
| (真, 真, 偽) | 8 |
| (真, 偽, 未定義) | 54 |
| (偽, 真, 真) | 150 |
| (偽, 真, 偽) | 24 |
| (偽, 偽, 未定義) | 82 |

- FR が未定義になるのは EU が偽のときに限られる（prop:fr_domain_eu）。
- 定義上ありうる 6 通りがすべて実際に現れた。
- 特に次の二つは、SM が EU・FR の言い換えではないことの具体例である。
  - 「$K$ の中にいるのに閉塞する」(真, 真, 偽)。例：避難所で $en=1$、資源はあるが贈与がない環境。資源は避難所からは食べられない。
  - 「$K$ の外にいるのに $A_t\neq\emptyset$」(偽, 真, 真)。例：避難所で $tp=0$、$en\ge2$。
- これは一つのモデルでの存在の例示であり、一般の独立性の証明ではない。

### 5.2 $\mu_{\mathrm{eff}}$ は核の中でほぼ 1

$x\in\mathrm{Viab}_f(K)$、$e\in E_{\mathrm{req}}(x)$ の組 156 のうち、$\mu_{\mathrm{eff}}=1$ が 148、$=2$ が 8 だった。

- $\mu_{\mathrm{eff}}=2$ は資源セルで $en=1$ かつ贈与がある境界的な状態にだけ現れる。
- v2 での観察（通常作動で $\mu_{\mathrm{eff}}=1$）が、このモデルでは全数で確かめられた。$\mu_{\mathrm{eff}}$ を原理の条件にしない判断と整合する。

### 5.3 二つの頑健性は一致しない（prop:robust_noninclusion）

- $\pi_X(\mathrm{Viab}^{\mathrm{resp}})\setminus\mathrm{Viab}_f(K)$ = {(0,1,1,1), (0,1,2,1)}。避難所にいてエネルギー 1 の状態である。
  - 状態だけを条件にする $\mathrm{Viab}_f(K)$ では、$E_{\mathrm{req}}$ に「資源あり・贈与なし」が含まれる。避難所ではその資源を食べられないため、頑健でない。
  - 応答込みでは $o$ を固定して量化する。$o=0$（資源なし）のもとでは、必要要因の充足に贈与が必須になるので、頑健になる。
- 逆向き $\mathrm{Viab}_f(K)\setminus\pi_X(\cdot)$ は空だった。
- したがって、本文の命題が存在を述べる二つの非包含のうち、(ii) の例がこのモデルで得られた。(i) の例はこのモデルにはない。

### 5.4 $E_{\mathrm{req}}$ に相対化する意味

すべての $e$ に対する頑健核は空（0 状態）だが、$\mathrm{Viab}_f(K)$ は 18 状態ある。$E_{\mathrm{req}}$ に限ることで初めて、頑健性の議論が空虚でなくなる例である（E5 の予備的な結果）。

### 5.5 7 タプルの成分を退化させると何が起きるか

| 変種 | $\lvert K\rvert$ | $\lvert\mathrm{Viab}_f(K)\rvert$ | B1 / B2 | EC を満たす状態 | CR-1 |
|---|---|---|---|---|---|
| 基準 | 20 | 18 | 136 / 608 | 36 | 成立 |
| $E=\emptyset$ | 20 | 0 | 0 / 744 | 36 | $E\neq\emptyset$ に反し ACS でない |
| $U=\{u_\emptyset\}$ | 20 | 0 | 136 / 616 | 36 | 成立（ただし $\mu_{\mathrm{eff}}\le1$） |
| $f$ が $e$ を読まない | 20 | 18（全 $e$ 頑健核と一致） | 0 / 720 | 0 | (a)(ii) が不成立（$\eta=0$ のまま存続する閉路がある） |
| $\Pi$ から体温の閾値を除く | 30 | 27 | 92 / 610 | 36 | 成立 |
| $M$・Update を退化（信念を学習しない） | 状態水準の集合は不変 | 不変 | 不変 | 不変 | 成立 |

- 最後の行は §1 の区別を具体的に示している。$X$ 上の集合（$K$・Viab・Crit など）は $M$ に依存しない。$M$ と Update の違いは、機構の振る舞いと軌道にだけ現れる（5.6）。

### 5.6 軌道（閉ループ、48 ステップ、判定は厳密）

| 背景列 | 学習あり：$T_{\mathrm{col}}$ | 学習なし：$T_{\mathrm{col}}$ |
|---|---|---|
| mild（短い寒波） | 崩壊なし、閉塞 0 回 | 11 |
| cold（長い寒波） | 崩壊なし、閉塞 4 回（すべて B1）から回復 | 11 |
| famine（資源の再生停止） | 17 | 11 |

- 学習なしでは、寒さの信念が初期値（寒くない）のまま更新されない。避難所の中では天候が見えないため、寒波の最中に外へ出ては戻ることを繰り返し、エネルギーを使い果たした（mild の t=6〜10）。
- famine の t=15 では、$x_t\in\mathrm{Viab}_f(K)$ でありながら閉塞（B1）した。このとき $e_t\notin E_{\mathrm{req}}(x_t)$ だった。prop:blockage_viability_kernel の前件（$e_t\in E_{\mathrm{req}}$）が外れると、核の中でも閉塞しうることを示す一例である。
- その後に届いた贈与（t=19・20）は崩壊後で、間に合わなかった。
- mild の学習ありでは、48 ステップすべてで選んだ行動が核維持応答 $U^{\mathrm{Viab}}$ に入っていた。観察区間内での「核維持応答の獲得」の例である。

## 6. 限界と、作成過程の開示

- **パラメータの事後調整。** 軌道を見たあとに、モデル（格子を 4→3→2 セル、エネルギーの上限を 4→5）と機構の閾値（2 回）を変えた。
  - 状態水準の結果（3・4・5.1〜5.5）は機構に依存しない。ただしモデルの変更には依存する。
  - 5.6 の軌道は調整後のもので、例示にとどまる。学習の有無の差を一般化しない。
- **最小性。** 「各概念が区別をもつ小さな一例」であり、これより小さい例が存在しないことは主張しない。
- **このモデルでは示せないもの。**
  - 機能的終端は崩壊と一致する（FTS $\iff s=0$。inject で回復できるため）。FT が CS に先行する例は v2 にある。
  - 状態帯 Z2（部分的な機能停止）は現れない。
  - prop:robust_noninclusion の (i) の例はない。
- **判定規則の固定。** WF・(SC-1)・活動・状態帯・Recover の規則はトイ規約である。
- **別の検証者による照合は未実施。**
