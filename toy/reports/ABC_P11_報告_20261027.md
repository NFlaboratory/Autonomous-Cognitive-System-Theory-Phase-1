# 実験 A・B・C と ACS 内の機構比較（P10・P11）報告（2026-10-27）

## 0. 位置づけ

- **問い：** 本文 §3 の命題 `prop:kernel_maintenance` は、二つの前件が任意の将来時刻まで続く限り、核にとどまり閉塞しないことを示している。
  - 前件：$x_T\in\mathrm{Viab}_f(K)$ の後、すべての $s\ge T$ で $e_s\in E_{\mathrm{req}}(x_s)$ と $u_s\in U^{\mathrm{Viab}}(x_s)$ が成り立つこと。
  - この条件付きの保証と、内部情報だけで作動する TIPA 機構との関係を三つの角度から測った。
- **三つの実験の役割**
  - A：前件が、実際の軌道でどれだけ続くか。
  - B：機構が核維持応答を選ぶか。B1 は有限時間の選択傾向、B2 は本文の定義どおりの獲得（`def:kernel_response_acquisition`）で、周期的な背景のもとでだけ厳密に判定できる。
  - C：どの前件が偽になったかを分類し、実際の結果（核にとどまったか、出たか）と、閉塞・$K$ の外への移行・崩壊を別に記録する。
- **分類は論理的な帰属であり、因果の主張ではない。** 「推定の誤りがあった」は同じ時刻に起きていたことの記録で、原因とはみなさない。
- **P11：** CR-2b を保ったまま、推定の分解能と更新の頻度を段階的に変えた変種どうしを比べた（ACS の中での機構比較）。

## 1. 手続き

- **登録**
  - P10：MinACS（md5 `f3ff9e8e…`）、炉番（`2ab8b9bc…`）、v2（r3：`c2cc967a…`）。
  - P11：MinACS（`66e28723…`）、炉番（`60df3abe…`）。
  - 仕様と登録記録は `specs/`・`registry.log` にある。
- **P10 は記述の集計である。** 仮説の検定はしない。登録した検査は、回帰検査（両前件が真の時刻に核から出る例はない）だけである。
- **評価用 seed と時間**
  - seed 11〜60。
  - MinACS・炉番は各 60 ステップ。背景と掃引は E1・E8 と同じ。
  - v2 は個体 i、300 ステップで、「他者なし」と「既定の世界」の二つの世界で行った。
- **周期的な背景（B2）**
  - 同じ掃引点から、seed で位置を固定した周期的な背景を作った。周期は MinACS が 12 と再生周期の最小公倍数、炉番が 12 である。
  - 結合状態（$x$、$o$、$M$、位相）が再び現れたら、そこから先の全時刻が周期の繰り返しになる。
  - その周期のすべての時刻で $u\in U^{\mathrm{Viab}}(x)$ なら「獲得」、一つでも外れれば「非獲得」と判定した。非獲得は外れが無限に繰り返されるので、反証になる。
  - 非周期の背景では「未判定」とした。v2 では B2 を行っていない。
- **v2 の扱い**
  - 核は証明書で判定する（所属／非所属／未決定）。
  - 証明書が与える $U^{\mathrm{Viab}}_{\mathrm{cert}}$ は $U^{\mathrm{Viab}}$ の部分集合なので、B1 の一致率は下限、C2・C3 は上限になる。
  - r1・r2 は、いずれもワーカーがメモリ不足で終了して止まった。結果を書き出す前で、評価用の出力は見ていない。
  - r3 では二点を変えた。一つは、判定層の後続表の蓄えに上限を設けたこと（結果は変わらない）。もう一つは、証明書の記録を単位ごとに持つようにしたことで、これにより単位の結果が実行順に依存しなくなる。
  - 単位の中では、$U^{\mathrm{Viab}}_{\mathrm{cert}}$ は「その状態を最初に含んだ証明書」に対するものになる。仕様に記載した。

## 2. 実験 A：核維持応答の表と、前件の持続性

**全数の表**（`outputs/kernel_tables/`）

- MinACS の核 18 状態、炉番の核 19 状態のそれぞれについて、核維持応答を一つ選んだ。$E_{\mathrm{req}}(x)$ のすべての環境で後続が核に入ることを確かめた（18/18、19/19）。
- この選び方を使い続ければ、必要環境が満たされ続ける限り、核に永久にとどまる。
- これは証明済みの命題の有限の例であり、新しい証明ではない。

**実際の軌道での前件の持続性（TIPA 機構、非周期の背景）**

| | MinACS | 炉番 |
|---|---|---|
| 生存中の時刻のうち $e\in E_{\mathrm{req}}$ | 0.593 | 0.867 |
| 必要環境の連続充足長の最大（単位ごとの中央値／最大） | 3／14 | 17／60 |
| 核の中で両前件が続いた最長の長さ（中央値／最大） | 3／14 | 7／16 |
| 両前件が 60 ステップ続いた単位 | 0 | 0 |
| 核から一度も出なかった単位 | 252 | 125 |

- 命題の前件が観察期間を通して続いた軌道は、二つの領域とも一つもなかった。
- それでも核から一度も出なかった単位がある（MinACS 252、炉番 125）。MinACS の 252 単位はすべて、必要環境が満たされない時刻を含んでいた。
- 保証の前件は十分条件であって、核にとどまるための必要条件ではない。

## 3. 実験 B：核維持応答の選択と獲得

**B1：選択傾向（有限時間）**

| | MinACS | 炉番 |
|---|---|---|
| 核の中の時刻で $u\in U^{\mathrm{Viab}}$ | 0.980 | 0.685 |
| そのうち $e\in E_{\mathrm{req}}$ の時刻 | 1.000（16,286/16,290） | 0.696 |
| 核の外で $u\in U^{\mathrm{Viab}}$（うち空虚な所属） | 267（0） | 0（0） |

**B2：獲得（周期的な背景、900 単位ずつ）**

| | MinACS | 炉番 |
|---|---|---|
| 獲得 | 456（周期がすべて核の中 429） | 0 |
| 非獲得：崩壊後の周期 | 441 | 443 |
| 非獲得：周期がすべて核の中 | 1 | 307 |
| 非獲得：その他 | 2 | 150 |
| 未判定 | 0 | 0 |

- 本文の獲得の定義は、条件に $E_{\mathrm{req}}(x_s)\neq\emptyset$ を含む。登録したコードの判定はこの条件を明示していないが、獲得と判定した周期に $E_{\mathrm{req}}(x)=\emptyset$ の時刻は両領域とも 0 だった（`outputs/p10_summary.md`）。表の件数は本文の定義による判定と一致する。
- MinACS の機構は、必要環境が満たされた核の中の時刻では、ほぼ必ず核維持応答を選んだ。周期的な背景では 456 単位で獲得が成立した。
  - 獲得が成り立ち、周期がすべて核の中だった 429 単位は、いずれも周期の中に $e\notin E_{\mathrm{req}}$ の時刻を含んでいた。
  - これらは環境の前件が破れても、実際には核に永久にとどまった例である。
- 炉番の機構は、獲得に一度も至らなかった。
  - それでも 307 単位では、周期全体を核の中で過ごした。核維持応答を選ばずに、核に永久にとどまったことになる。
  - 核維持応答は「$E_{\mathrm{req}}$ のすべての環境で核を保つ一つの行動」である。実現した環境に限れば、それ以外の行動でも核を保てる場合があるためである。
- 獲得と核の維持は別の性質である。本文はこの二つを区別しており（`def:kernel_response_acquisition`、`rem:kernel_response_scope`）、結果はその区別の具体例になった。

## 4. 実験 C：前件の分類と実際の結果

生存中の時刻の分類と、そのうち核から出た時刻：

| 分類 | MinACS | 炉番 |
|---|---|---|
| OK（両前件が真） | 16,286（出た 0） | 18,405（出た 0） |
| C1 環境の前件だけ偽 | 10,729（出た 267） | 1,959（出た 64） |
| C2 選択の前件だけ偽 | 4（出た 0） | 8,028（出た 0） |
| C3 両方偽 | 555（出た 543） | 1,354（出た 904） |
| C0 核の外 | 1,163 | 1,425 |

- **回帰検査：** 両前件が真の時刻に核から出た例は 0 だった（両領域、登録した検査も支持）。
- **核から出たのは、環境の前件が偽の時刻だけだった。** C1 と C3 がこれに当たる。選択の前件だけが偽の時刻（C2）には、核から出た例は 0 だった。
- **出来事の帰属**（出来事の前に最後に核にいた時刻の分類）
  - MinACS：崩壊 526 件はすべて C3。
  - 炉番：崩壊は C3 469、C3 で推定の誤りあり 167、C1 で推定の誤りあり 48。
  - 推定の誤りは同じ時刻に起きていた記録であり、原因の主張ではない。
- **MinACS と炉番で言えること：** 保証が外れて核から出る局面には、必ず必要環境の欠損が含まれていた。選択の誤りだけで核から出る局面は現れなかった。v2 では現れた（5 節）。

## 6. P11：ACS の中での機構比較（CR-2b を保つ変種）

検査：CR-2b は MinACS・炉番の est-2・est-3 で成り立った。upd-k は Update だけを変えるので、CR-2b は基準の機構と同じである（`outputs/cr2_variants.md`）。

**判定（崩壊到達時刻、900 単位ずつ）**

| 仮説 | MinACS | 炉番 |
|---|---|---|
| H1 base ≥ est-2 | 支持 | 支持 |
| H2 est-2 ≥ est-3 | **不支持** | **不支持** |
| H3 base ≥ est-3 | **不支持** | 判定不能 |
| H4 base ≥ upd-2 | 判定不能 | 支持 |
| H5 upd-2 ≥ upd-4 | 判定不能 | 判定不能 |
| H6 upd-4 ≥ upd-none | 判定不能 | **不支持** |
| H7 base ≥ upd-none | 支持 | 判定不能 |

**記述（60 ステップ生存の単位数と、核の中の時刻での核維持応答の選択率）**

| 変種 | MinACS 生存 | MinACS 選択率 | 炉番 生存 | 炉番 選択率 |
|---|---|---|---|---|
| base | 374 | 0.980 | 216 | 0.685 |
| est-2 | 163 | 0.956 | 0 | 0.653 |
| est-3 | 587 | 0.993 | 164 | 0.685 |
| upd-2 | 261 | 0.970 | 81 | 0.694 |
| upd-4 | 176 | 0.961 | 94 | 0.686 |
| upd-none | 173 | 0.958 | 215 | 0.702 |

- **分解能を下げると一様に悪くなる、という順序は成り立たなかった。** MinACS では est-3 が基準よりも長く存続した（生存 587 対 374）。
  - 量子化は切り捨てなので、分解能の低下は同時に「エネルギーを少なめに読む」偏りを伴う。
  - est-3 ではこの偏りが大きく、食料に早く向かう方向に働いたと考えられる（要因分析は未実施）。E7 で過大推定が致命的だったことと、逆向きの結果である。
  - この設計では、分解能と偏りの効果を分けられていない（限界）。
- **更新の頻度も一様ではなかった。** 炉番では「更新しない」変種が、4 ステップごとの更新より長く存続した（H6 不支持）。
- **ACS の中で比べても、推定や更新の「質」と存続の長さは単調に対応しなかった。** これは E2・E7 の結果と同じ方向である。

## 7. 論文への含意（主張の上限）

- 命題 `prop:kernel_maintenance` の前件は、この二つのトイの環境ではほとんど満たされ続けなかった。保証は、適用できる範囲が狭い十分条件として働いた。
- 核維持応答の獲得は、機構と環境によって成立する場合もしない場合もあった（MinACS で成立、炉番で不成立）。獲得なしに核にとどまる軌道もあった。
- 保証が外れる局面の型は、領域によって異なった。MinACS・炉番では、核からの離脱にはすべて必要環境の欠損が伴った。v2 では、選択の前件だけの破れによる離脱も現れた。
  - 本文の非主張（`rem:kernel_response_scope`）と、§9 に追加を提案した「核維持応答の獲得条件」の問題に、具体例を与える。
- 一般的な傾向や条件は主張しない。二つの小さなモデルと一つずつの機構での例示である。

## 8. 限界

- 周期的な背景は、評価用の非周期の背景とは別に作ったものである。B2 の結果は、その周期的な背景についてだけ言える。
- P11 の推定の変種は、分解能と偏りの効果を分けていない。
- v2 の B1・C は、証明書に依存する下限・上限である。
- 作り手と別の検証者による照合は未実施である。
