## 2. 第二の領域：炉番

MinACS とは、次の点で構造が異なる。

| | MinACS | 炉番 |
|---|---|---|
| 移動 | あり（避難所と資源セル） | なし（定常系） |
| 危険の向き | 一方向（寒さ・飢え） | 二方向（凍結と過熱） |
| 必要環境要因 | 熱（条件型）、食料（物質型） | 燃料（物質型）、煙道（排出型） |
| 自分の行動による必要要因の破壊 | 食べると資源が減る | 燃やすと煙道が煤で塞がりうる（開ければ戻る） |
| 状態数 $\lvert X\rvert$ | 72 | 60 |

- $X=(\mathit{fu},\mathit{tp},s)$：燃料 0〜4、温度 0〜5、構造 {0,1}。
- $U$={待機, 燃やす, 集める, 開ける}。
- $e=(h,d,k,o)$：外気（暑い／寒い）、燃料の配達、悪い通風、煙道が開いているか。$|E_{\mathrm{ext}}|=16$。
- $\Pi(x)=\min(\mathit{tp}-1,\ s-1)$。
- 寒い外気で温度 0、または暑い外気で温度 5 のとき、構造が失われる。温度 4 以上で燃やすと亀裂が入る。
- これらはすべてトイの規約で、本文の定義ではない。

## 4. 読み取れること

1. **判定層は二つの領域にそのまま適用でき、全数検査の結果も同じ形になった。**
   - 回帰検査（E1 の H1）は二つの領域で成り立った。
   - 全数検査の命題はすべて OK だった。
   - ただし、これは実装の正しさの確認である。命題はもともと証明されているので、これらは本文の命題を補強しない。
2. **方策の比較の結論は、領域によって変わった。**
   - MinACS では「核維持応答の選択 ≥ 一段先を見る方策」が支持された（H2）が、炉番では不支持だった。
   - 理由と考えられること（要因分析は未実施）
     - $U^{\mathrm{Viab}}$ は実現した $e$ を見ない。
     - 炉番では、煤による煙道の閉塞や燃料の途絶（$e_t\notin E_{\mathrm{req}}$）が、ほぼすべての単位で生じた（P-Viab-first で 893 単位）。
     - そのため、本文の命題（prop:kernel_maintenance）の前提が外れる時刻が多い。
   - 逆に、MinACS で不支持・判定不能だった「機構 ≥ 観測反射」「機構 ≥ 固定行動列」は、炉番では支持された。
   - **どの方策が長く存続するかは領域に依存する**、というのがこの比較から言えることである。
3. **除去実験で v2 と炉番に共通して存続が短くなったのは、可行性感応評価と応答可能性評価の除去だった。**
   - ほかの群は、領域によって判定が異なるか、判定不能だった。
   - 可行性感応評価の除去は、この機構では寒さ・暑さ・燃料の要請をすべて止める。そのため E2 と同じく、「要請の唯一の経路を外した」ことの確認に近い。
4. **除去が効かなかった群には、実装上の理由がある。**
   - **物理的感知・作用・基盤維持（PSL-4）：** 完全な機構の軌道で、保護応答は一度も発火しなかった（評価用の全単位で 0 回）。M3 が暑い外気で温度 3 以上になると冷やす目的をとるため、発火条件（温度 4 以上）に達しない。この群の効果は、この機構では観測できない。
   - **情報取得・統合と時間横断的更新：** 900 単位すべてで同じ結果になった。Update を恒等にすると時間統合の記録も失われ、二つの除去が同じ働きになる。E2 で見た「群と実装部位の対応が一対一でない」ことが、ここでも起きている。
5. **崩壊の経路は領域ごとに異なった。**
   - 炉番では、過熱による崩壊がある（固定行動列・待機・観測反射・P-A-first）。
   - 自分の行動による亀裂で、生存中に一度も閉塞を経ずに崩壊した単位もあった（固定行動列の 66 単位。$u_t\notin A_t$ を選んだ結果）。
   - $A_t$ から選ぶ方策では、崩壊した単位はすべて生存中に閉塞を経ていた。

## 5. 論文への含意（主張の上限）

- 判定層（本文の定義の計算）が、構造の異なる二つの有限領域に同じ手順で適用できることの例示である。領域一般への妥当性は主張しない。
- 方策の比較（MinACS との比較）と除去実験（v2 との比較）の結論のうち、領域をまたいで一致したのは次の 4 点に限られる。
  - 回帰検査
  - 「機構 ≥ 常に待機」
  - 可行性感応評価と応答可能性評価の除去で、存続が短くなること
- それ以外の結論は、領域と機構の設計に依存した。したがって、E1・E2 の個々の結論をトイ一般の性質として述べることはできない。
- 査読者の Q7 に対しては、「判定層の適用可能性は二領域で例示できた。方策や機能群の効果は領域に依存する」と答えるのが、このトイから言える範囲である。
