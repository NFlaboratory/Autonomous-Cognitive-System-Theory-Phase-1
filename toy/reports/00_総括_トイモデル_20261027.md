# ACS理論 Phase 1 のトイモデル：総括（2026-10-27）

本書は、このリポジトリのトイモデルと実験の結果をまとめたものである。各実験の詳細は同じフォルダの個別報告にある。個別報告は開発中に書いたもので、フォルダ名が当時のもの（`TOY2/`、`MINACS/`、`E4/`、`E8/` など）になっている。現在の配置との対応は README の表を参照のこと。

## 0. 準拠する本文

- トイは、公開する原稿より前の時点の本文に準拠して作った。その本文でも三原理は SM・EU・FR で、$\mu_{\mathrm{eff}}$ は原理の条件ではなく診断量として扱われている。
- その後の本文の改訂のうちトイに関わるのは、次の三点である。
  - 組織ACSの成立に参加ACS数の条件を置かない。v2 の組織水準の判定はこれに合わせてある（README 8 節）。
  - 核維持応答の獲得（`def:kernel_response_acquisition`）は、条件に $E_{\mathrm{req}}(x_s)\neq\emptyset$ を含む。登録したコードの判定（`e4/adapters.py` の `_b2`）はこの条件を明示していない。ただし、獲得と判定した周期に $E_{\mathrm{req}}(x)=\emptyset$ の時刻は MinACS・炉番とも 0 だった（`outputs/p10_summary.md` の「空虚な所属を含む周期 0」）。したがって獲得の件数は、本文の定義で判定した場合と一致する。
  - PSL の最小構造条件（`ass:psl_minimal`）の (4) は、局所保護応答を生成する局所信号が存在することを求める。v2 と炉番の完全な機構はこれを満たす（`acs_toy/mind.py`・`domains/furnace/mind.py` の `Phi_prot`）。MinACS の機構は PSL-4 を実装しておらず、「物理的感知・作用・基盤維持」の除去の変種は保護応答を一度も生成しない。これらは同仮定の範囲の外にある。トイは §4 の仮定の充足を主張しておらず、CR-2 の充足も変わらないので、判定と比較の結果は変わらない。
- トイのコードと報告で参照している本文のラベル 90 件は、すべて現行の原稿（`paper/`）に実在することを確かめた（実測）。

## 1. トイの目的と、示せることの上限

- **目的：** 形式的に与えた構造が、環境の中で更新しながら自律的に振る舞うか。その結果として、可行性の維持、閉塞、回復を経験し、最後には崩壊するか。これを、本文の定義どおりの判定で観察する。
- **示せること**
  - ある有限の実現が存在し、本文の定義と構成要件を同時に満たすこと。
  - 本文が区別する概念が、実際に別々に現れる例があること。
  - 本文の命題の前提が外れる状況で、何が起きるかの記述例。
- **示せないこと**
  - 本文の命題の補強。命題はすでに証明されている。トイの検査は、実装が定義どおりであることの確認である。
  - 一般的な傾向や、現実の系（生物・AI・組織）への適用可能性。
  - 三原理に従うことや、機構を備えることの優位。後述のとおり、トイは優位を支持しなかった。

## 2. 三つの領域と共通判定層

| 領域 | 規模 | 特徴 | 集合の計算 |
|---|---|---|---|
| v2 トイ（`acs_toy/`） | 7×7 格子、2 個体、ドローン、組織 | §2〜§8 の構造形式をすべて実装。関係・救助・組織を含む | 核は証明書方式（構成できれば所属、有限の地平なら非所属） |
| MinACS（`minacs/`） | 状態 72、行動 4、環境 16 | 移動と採食、寒さと食料 | 全数 |
| 炉番（`domains/furnace/`） | 状態 60、行動 4、環境 16 | 移動なし、凍結と過熱の二方向の危険、自分の燃焼で塞がりうる煙道（排出型の必要要因） | 全数 |

- **判定層と機構の分離：** 判定層は真の $f$・$K$・$E$ を使い、本文の定義どおりに判定する。機構（TIPA・PSL・ISL）は観測 $P_{\mathrm{sens}}$ と内部状態 $M$ だけを使い、真の $\Pi$・$A_t$・核を参照しない。
- **$K$ と基盤機能・構造の対応（トイの規約）：** 三つのトイでは、$K$ のどの状態でも基盤機能が作動し、構造が保たれている（MinACS・炉番は全数で確認、v2 は閾値の定義から従う）。このため、トイの中では「$K$ にとどまること」から「機能的終端にも崩壊にも至らないこと」が従う。これはトイの規約による対応であり、本文の一般的な帰結ではない。本文は $x_t\in K$ から機能的終端や崩壊の不在を導かない。
- **共通判定層（`acsjudge/`）：** 領域に依存する部分（$X$、$U$、$E_{\mathrm{ext}}$、$f$、$\eta$、$\Pi$、$O$ とその更新）を差し替えられる。MinACS 専用の解析と全数で一致することを確かめた（54 項目で不一致 0）。

## 3. 手続き

- **事前登録（E4）：** 仮説、判定規則、掃引、seed の分割（調整用 1〜10、評価用 11〜60）を、ソースの md5 とともに凍結してから実行した。
- **判定：** 登録した規則だけで「支持／不支持／判定不能」に分け、件数を併記した。崩壊しなかった単位は $+\infty$ として比べた。
- **反証の条件の明記：** P1 で、構造上ほぼ失敗しえない仮説を登録してしまった。この反省から、各仮説に「何が起きれば反するか、それがこのモデルで起こりうるか」の記載を必須にした。
- **開示：** 登録前の試運転と、その後の変更はすべて仕様に記載した。

## 4. 結果

### 4.1 定義系の実現（v2、E6、E8）

- **定義系が同時に満たされる実現が存在する。**
  - v2 の 8 シナリオで、検査の NG は 0 だった。
  - MinACS（26 項目）と炉番（31 項目）は全数検査で NG 0 だった。対象は、CR-1・CR-2、§2 の仮定、§3・§7 の命題 14 件である。
  - 有限の全数検査なので、この二つの実現についてはそのまま証明になる。v2 の CR-1a(ii) などは格子検査で、証明ではない。
- **定義域の制限のもとで許される (SM, EU, FR) の 6 通りの判定の組が、MinACS の有限の実現ですべて現れた。** FR は EU が偽の時刻には定義されないので、三つは独立な二値述語ではない。6 通りは (SM 真偽) × {(EU 真, FR 真), (EU 真, FR 偽), (EU 偽, FR 未定義)} であり、FR が未定義の組を FR 偽としては数えていない。例として、$K$ の中にいるのに閉塞する組（8）、$K$ の外にいるのに可行な行動がある組（150）がある。これは一つのモデルでの存在の例示である。
- **$\mu_{\mathrm{eff}}$ は通常作動ではほぼ 1 だった。**
  - MinACS の核の中で $E_{\mathrm{req}}$ が満たされた組では、156 組中 148 組で 1 だった。
  - v2 では、通常作動帯の全時刻で 1 だった。
  - これは $\mu_{\mathrm{eff}}$ を原理の条件にしない判断と整合する。
- **本文が区別する概念が、実際に別々に現れた（v2）。**
  - 閉塞からの自律的な回復があった。
  - B1 と B2 の両方が現れた。
  - 機能的終端が崩壊に先行した。
  - 個体の崩壊と組織水準の崩壊が、別の時刻に起きた。

### 4.2 方策の比較（E1：MinACS・炉番・v2）

| 仮説 | MinACS | 炉番 | v2（他者なし） | v2（既定の世界） |
|---|---|---|---|---|
| 回帰検査（核維持応答で核から出るのは $e_t\notin E_{\mathrm{req}}$ のときだけ） | 支持 | 支持 | 支持 | 支持 |
| 核維持応答 ≥ 一段先だけを見る方策 | 支持 | 不支持 | 支持 | 支持 |
| 核維持応答 ≥ TIPA 機構 | 不支持 | 不支持 | 不支持 | 不支持 |
| 機構 ≥ 観測反射（記憶なし） | 不支持 | 支持 | 不支持 | 不支持 |
| 機構 ≥ 固定行動列 | 判定不能 | 支持 | 支持 | 支持 |
| 機構 ≥ 常に待機 | 支持 | 支持 | 支持 | 支持 |

- 核維持応答を選び続ける方策は、どの領域でも機構に及ばなかった。v2 では、300 ステップを一度も生き延びなかった。
- その崩壊の大半は、必要環境要因が満たされない時期（MinACS の寒波、v2 の厳寒、炉番の煤）の直後に起きた。核維持応答は、$E_{\mathrm{req}}$ の中で持続することだけを扱い、実現した $e$ を見ないためである。
- この結果は命題 prop:kernel_maintenance と矛盾しない。命題の前提の外で何が起きるかを示す記述例である。

### 4.3 機能群の除去（E2：v2・炉番）

| 除去した機能群 | v2 | 炉番 |
|---|---|---|
| 情報取得・統合 | 不支持 | 判定不能（同値 871） |
| 可行性感応評価 | 支持 | 支持 |
| 応答可能性評価・再構成 | 支持 | 支持 |
| 環境利用・外部結合評価 | 支持 | 判定不能 |
| 応答形成・選択 | 支持 | 判定不能 |
| 時間横断的情報保持・更新 | 不支持 | 判定不能（同値 871） |
| 物理的感知・作用・基盤維持 | 判定不能 | 判定不能（全単位で同値） |

- 二つの領域に共通して存続が短くなったのは、可行性感応評価と応答可能性評価の除去だった。
- ただし、v2 の可行性感応評価・環境利用評価の除去と、炉番の可行性感応評価の除去は、「要請の唯一の経路を外せば存続できない」ことの確認に近い。
- 除去の実装は一意でない。群と実装部位の対応も一対一でなく、二つの除去が同じ働きになった例がある。
- v2 では、関係と救助の担い手を除くと存続がむしろ延びた（個体 i の生存 117→331）。

### 4.4 警告としての判定量（E3：MinACS）

- 核の外・$K$ の外・閉塞の警告は、崩壊の 1〜2 ステップ前に点き、見逃しは 0 だった。生存軌道で点いていた時刻の割合は平均 3.7% だった。
- 素朴な閾値（エネルギー・体温が 1 以下）は約 5 ステップ前に点くが、生存軌道でも平均 24% の時刻で点いていた。
- 核の外の警告が素朴な閾値より早く点いた軌道は 0 だった。判定量は「崩壊直前の状態を、誤警報少なく特定する」診断量であり、早期警告としての有用性は示していない。

### 4.5 推定誤差（E7：MinACS）

- エネルギーを 1 だけ過大に読むと、生存は 374 単位から 0 単位になった。
- 体温を過大に読むと、166 単位で内部評価と真の $\Pi$ の符号が食い違ったが、存続は全単位で同じだった。機構が体温を行動の選択に使っていないためである。
- 「内部評価の誤り ≠ 行動の誤り ≠ 存続への影響」という三段の区別の具体例になった。

### 4.6 標準の可行性の定式化との比較（E5：MinACS・炉番）

- 全 $e$ に対する頑健核は空で、楽観核は $K$ と一致した。どちらも区別を与えなかった。
- $E_{\mathrm{req}}$ 相対の核は、その間にある空でない真部分集合だった（18／20 状態、19／25 状態）。
- 核の中での閉塞は、すべて $e\notin E_{\mathrm{req}}$ の組だった。$K$ の外に出たあと崩壊せずに戻った回もあった（MinACS 259／801、炉番 144／828）。
- $\mathrm{Viab}_f(K)$ は、状態に依存する外乱集合 $E_{\mathrm{req}}(x)$ に対する保証付きの核と見ることができる。違いは核の概念ではなく、外乱集合を必要環境要因から定める点にある。優越性は主張しない。

### 4.9 条件付きの長期可行性と自律機構の接続（実験 A・B・C、P11）

詳細は `ABC_P11_報告_20261027.md`。

- **A（前件の持続性）：** 命題 `prop:kernel_maintenance` の前件（$e_s\in E_{\mathrm{req}}(x_s)$ と $u_s\in U^{\mathrm{Viab}}(x_s)$ が続くこと）が観察期間を通して続いた軌道は、MinACS・炉番とも 0 だった。それでも核から一度も出なかった軌道がある（252・125）。保証は、適用範囲の狭い十分条件として働いた。
- **B（選択と獲得）**
  - 核の中で $e\in E_{\mathrm{req}}$ の時刻に核維持応答を選んだ割合は、MinACS 1.000、炉番 0.696、v2 0.36〜0.67（下限）だった。
  - 本文の定義どおりの獲得を周期的な背景で判定すると、MinACS で 456/900 単位、炉番で 0 だった。
  - 炉番では、獲得せずに核に永久にとどまった単位が 307 あった。
- **C（保証が外れた局面）**
  - 両前件が真の時刻に核から出た例は、三つの領域とも 0 だった（回帰検査）。
  - 核から出たのは、MinACS・炉番では必要環境の欠損を伴う時刻だけだった。
  - v2 では、選択の前件だけが偽の時刻にも核から出た（他者なし 407、既定の世界 3）。
- **P11（CR-2b を保つ変種どうしの比較）：** 推定の分解能や更新の頻度を下げると一様に存続が短くなる、という順序は成り立たなかった。MinACS では、エネルギーを粗く（少なめに）読む変種が基準より長く存続した。

## 5. 横断して言えること・言えないこと

**言えること（例示の水準）**
- 本文の定義系には、有限で決定論的な実現が存在する（三つの領域）。
- 三原理の述語、閉塞と崩壊、全機能停止と崩壊、核と $K$ は、実現の上で別々に現れる。
- $E_{\mathrm{req}}$ への相対化によって、全 $e$ 頑健核と楽観核のどちらでも区別がつかない場面で、空でない区別が得られた。
- 本文の命題の前提が外れる時期（必要環境要因の欠損）に、何が起きるかの記述例が得られた。

**言えないこと**
- 核維持応答を選ぶこと、三原理に沿うこと、機能群を備えることが、存続を延ばすこと。どの領域でも支持されなかった。
- 機構の優劣の一般的な順序。領域によって判定が分かれた。
- 判定量が崩壊の早期警告になること。
- 結果の一般性。モデルも機構も小さく、同じ一人の設計者によるものである。

## 7. 限界と開示

- **調整：** モデルと機構は、現象が現れるように設計者が調整した。調整の経緯は各報告と仕様に記載した。
  - v2 の機構は seed 1 で調整した。
  - MinACS は、軌道を見たあとに格子と閾値を変えた。
