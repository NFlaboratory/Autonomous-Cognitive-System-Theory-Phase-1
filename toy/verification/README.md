# 検証スイート（toy/verification/）

既存のトイ（MinACS・炉番・v2）では確かめていなかった本文の命題・仮定・定義を、有限の範囲で照合する道具一式です。小さな世界も二つ追加しました。

この道具は論文の外の付属物で、本文の定義・命題を変えません。既存の事前登録実験（experiments/・specs/・results/・registry.log）も変えません。

## 1. 位置づけ（必ず読むこと）

- **何を確かめるか：** ここで行うのは、有限の世界の上で本文の文言どおりに計算した照合です。本文の命題の証明は本文が担っており、この照合はそれを補強しません。
- **部分模型：** 新しい二つの世界（綱渡り・乾眠）と全模型列挙（MicroUniverse）は「部分模型」です。部分模型とは、(X, U, E, f, Π, O, g_O) だけを持ち、機構（TIPA・PSL）を持たない世界のことです。
  - 構成要件 CR-2 は判定していないので、ACS とは呼びません。
  - 照合するのは、これらの成分だけで述べられた §3 の命題に限ります。
  - 照合で例外が出ても、それを ACS 一般への反例とは扱いません。
- **トイ規約：** 世界の状態・規則・判定規則（乾眠の (SC-1)(SC-2)(FT-1)(FT-2) など）は、すべて実行の前に固定したトイ規約です。本文の定義ではありません。
- **構造の検査が合格した意味：** 「この実装が、述べた条件を有限範囲の全体で満たした」という意味です。抽象構造の証明でも、機構が有効であることの判定でもありません。
- **作り手と検証者：** このスイートは作り手（言語モデル）が実装しました。人による第三者の検証は行われていません。

## 2. 判定区分（実行の前に固定）

| 区分 | 意味 |
|---|---|
| PASS_NONVACUOUS | 述べた有限範囲の全件で成り立ち、前件が成り立つ場合が 1 件以上あった |
| PASS_VACUOUS | 全件で成り立ったが、前件が一度も成り立たなかった（証拠にならない） |
| EXAMPLE_ONLY | 例・実現を示しただけで、全称の照合はしていない |
| FAIL | 反例が見つかった（証拠を保存） |
| BLOCKED_ASSUMPTION | 本文の仮定がその世界では成り立たない。結論は別に報告し、反例とは扱わない |
| BLOCKED_SOURCE | 必要な部分がトイのソースにない |
| NOT_RUN / NOT_APPLICABLE | 実行していない／当てはまらない（理由を併記） |

## 6. 述べてよいこと・述べないこと

- **述べてよい：**
  - 有限の範囲で、本文の文言どおりに計算して照合し、反例が出なかったこと（件数と範囲を添える）
  - 強仮定が成り立つ有限の世界（MinACS・綱渡り）と、成り立たない有限の世界（炉番）があること
  - (SC-1)・(FT-1) と CS・FTS が別々に現れる例があること
  - 収束しない Update 則の有限の例があること
- **述べない：**
  - 本文の命題の補強
  - 一般的な傾向
  - 現実の系への当てはまり
  - 部分模型を ACS と呼ぶこと
  - 強仮定の不成立を「系の反例」と呼ぶこと
  - Update 則のあいだの優劣
